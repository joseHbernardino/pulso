Console

Execute um comando ou um script bash neste servidor. Cada execução fica registrada na auditoria.

O console exige uma conta de administrador. Com acesso de visualização é possível acompanhar as aplicações, mas não executar comandos.

Comando

Linha de comando completa: canos, condicionais e redirecionamentos funcionam. Várias linhas são executadas como um script.

Ctrl+Enter executa. O comando roda com o usuário do Pulso, na pasta indicada abaixo.

Uma aplicação empresta sua pasta, variáveis e .env.
