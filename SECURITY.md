# Security policy

Report security vulnerabilities privately to the maintainers of the repository
where this copy of Pulso is published. Use its private vulnerability reporting
channel when available. Do not include credentials or exploit details in a
public issue.

A standalone development copy has no hosted reporting destination configured.
Before publishing a release, maintainers must enable private vulnerability
reporting and add their contact information here.

Include the affected version, a description, reproduction steps and potential
impact. Publish coordinated advisories after fixes are available.
